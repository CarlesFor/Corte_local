Editor de vídeo para Windows de 64 bits, en español, con ejecución local y sin cuentas ni suscripciones.

## Descargar y empezar

- **Corte-Local-Windows.exe**: opción recomendada. Descarga el archivo y haz doble clic para abrir el editor, sin instalar nada más. La primera apertura tarda unos segundos mientras se prepara la aplicación.
- **Corte-Local-Instalador-Windows.exe**: instalación normal con acceso directo.
- **Corte-Local-Windows.zip**: extrae toda la carpeta y abre **Corte Local.exe**. Conserva los archivos y carpetas que lo acompañan.

Importa un vídeo y empieza a editar. Para los subtítulos automáticos, descarga una sola vez el modelo **small / Equilibrado** desde **Ajustes**. Después también funcionan sin conexión. FFmpeg, FFprobe, Whisper y las fuentes ya están incluidos.

## Incluye

- Recorte, división, unión, duplicación y deshacer/rehacer.
- Vídeos e imágenes superpuestos en varias pistas, con colocación rápida en una esquina.
- Forma de onda de audio para localizar silencios.
- Subtítulos automáticos en español, con fuentes, bordes y fondos personalizables.
- Exportación MP4 hasta 1080p y subtítulos SRT/ASS.
- Proyectos guardados y recuperación local.

No incluye modelos de voz en la descarga inicial. Los ejecutables no llevan firma digital. **Source code (zip)** y **Source code (tar.gz)** son para desarrollo; para usar el editor, descarga uno de los archivos de Windows de arriba.

SHA256SUMS.txt contiene las huellas de las tres descargas.
